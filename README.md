# Zerodha Landing Page Clone

This is a clone of the Zerodha landing page built using **HTML** and **CSS** as part of Week 0 of [Harkirat Singh's Cohort 2.0](https://www.instagram.com/hkiratsingh/). The project aims to replicate the design of Zerodha's official homepage to practice and demonstrate core front-end development skills.

## 🚀 Features

- Responsive layout mimicking Zerodha’s landing page
- Clean HTML5 structure
- Modern and consistent styling using CSS
- Pixel-perfect alignment and spacing
- Mobile-friendly using media queries (if added)

## 🛠️ Tech Stack

- HTML5
- CSS3
